## Protocol

1. Fresh install; complete onboarding; grant microphone and notification permission.
2. Start capture from the visible home screen. Confirm the persistent notification says **Recording — transcript only** and the microphone indicator is on.
3. Set a schedule block that covers the test window (or use the default sleep block). Confirm the notification switches to **Paused — outside the schedule** and the microphone indicator turns off within one tick (≤ 30 s).
4. Leave the phone screen-off for 8 h. Every hour record:
   - `adb shell dumpsys activity services io.github.markyu0401.everheard | grep -E "isForeground|foregroundNoti"`
   - `adb shell dumpsys battery | grep level`
   - `adb shell dumpsys thermalservice | grep -E "Thermal Status|status"`
   - `adb shell dumpsys notification --noredact | grep -A5 "pkg=io.github.markyu0401.everheard"`
5. At the end: stop the service, export logcat (`adb logcat -d > soak.log`), and record crashes/ANRs.
6. Repeat the 8 h run on the second ROM. For the paused budget, run a second 8 h window entirely inside the schedule block.
